# Football Labs Landing Page

Pour voir le rendu de la page, vous avez deux options simples :

1. **Ouvrir le fichier directement**
   - Double-cliquez sur `index.html` depuis votre explorateur de fichiers, ou ouvrez-le dans votre navigateur préféré.

2. **Utiliser un petit serveur local (recommandé)**
   - Dans ce dossier, exécutez l'une des commandes suivantes, puis ouvrez http://localhost:8000 dans votre navigateur.
     ```bash
     # Avec Python 3
     python3 -m http.server 8000

     # Avec Node.js (si installé)
     npx serve .
     ```

Cela vous permettra de visualiser la navigation noire avec le logo à gauche et les liens centrés comme sur la maquette.
